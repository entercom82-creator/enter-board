# 엔터 상황판 (Windows)

엔터 매장운영앱의 매장 상황판을 PC 화면 위에 띄워 두는 Windows 프로그램입니다.
PC방 관리 프로그램 위에 항상 떠 있고, 배경·글자 투명도를 따로 조절할 수 있습니다.

## 내려받기

[최신 설치 파일 내려받기 (EnterBoard-Setup.exe)](https://github.com/entercom82-creator/enter-board/releases/latest/download/EnterBoard-Setup.exe)

## 설치

1. 내려받은 `EnterBoard-Setup.exe`를 실행합니다.
2. 'Windows의 PC 보호' 창이 뜨면 [추가 정보] → [실행]을 누릅니다. (서명하지 않은 프로그램이라 뜨는 창입니다.)
3. 설치가 끝나면 첫 화면에 상황판 주소를 붙여 넣습니다. 주소는 매장운영앱 관리 → 매장의 '매장 PC 상황판 주소'에서 복사합니다.

자세한 사용법은 매장운영앱 설명서의 '매장 상황판' 장을 보세요.
이 저장소에는 설치 파일만 올립니다.
